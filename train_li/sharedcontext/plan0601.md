# Plan 0601 — Pipeline Optimization Plan (5 Steps)

## Background

Full pipeline audit revealed a **critical bug**: cross-sectional features (rank(pct_chg), rank(amount), rank(turnover_rate), rel_beta) are tiled to all 60 timesteps then Z-score normalized per-window → all become exactly zero. Model trains on 18 effective features, not 22.

Additionally, 16 columns from raw data (vwap, pe, pb, circ_mv, etc.) are dropped during preprocessing.

## Step 1 — Fix Features + Retrain Baseline (P0 + P1)

**Fix the cross-sectional normalization bug and add new valuation features.**

### Feature Layout After Fix (26 dims total)

| Group | Features | Count | Normalization |
|-------|----------|-------|---------------|
| Raw | open, high, low, close, vol, amount, pct_chg, turnover_rate, volume_ratio, total_mv, **vwap_gap** | 11 | Per-window Z-score across T |
| Tech | macd, macd_signal, rsi, bb_width, bb_pct, mom_5, mom_20, vol_20 | 8 | Per-window Z-score across T |
| Cross | rank(pct_chg), rank(amount), rank(turnover_rate), rel_beta | 4 | Per-date Z-score across N → tiled |
| Valuation | **rank(pe)**, **rank(pb)**, **rank(circ_mv)** | 3 | Per-date Z-score across N → tiled |

Key: `vwap_gap = close/vwap - 1` (daily, institutional activity signal).

## Step 2 — T+N Label (P2)

**Replace T+1 label with T+3 or T+5 cumulative return.**

Modify `v5/build_windows.py`: label = sum(pct_chg[t+1:t+N]) or cumulative product.
Rebuild windows → retrain → compare val IC with Step 1 baseline.

Expected: higher SNR because single-day noise cancels over multi-day horizons.

## Step 3 — Spatial Attention (D, reborn)

**On top of fixed feature set from Step 1 or Step 2.**

Implement `SparseSpatialAttn` as described in SPATIAL_ATTENTION_PLAN.md.
KNN proxy verification (v4/verify_spatial.py) showed +0.0049 IC gain.
With fixed cross-sectional features, neighbors are more meaningful.

## Step 4 — Attention Pooling Over Time (P3)

**Replace GRU last-hidden with learnable attention pooling across all timesteps.**

Add ~128 parameters (one Linear(128,1)). Let the model learn which timesteps matter.
Can be combined with spatial attention (Step 3).

## Step 5 — Adaptive Strategy B (P4)

**Replace fixed csi5d < -1.0% threshold with rolling percentile.**

No training needed — pure backtest on benchmark data.
Expected: better regime adaptation (tighten in low-vol, loosen in high-vol).

## Fallback

If Step 1 doesn't improve IC → the bug fix alone isn't enough, fall back to current GRU (v2 checkpoint) + Strategy B. Nothing lost — the old pipeline still works.

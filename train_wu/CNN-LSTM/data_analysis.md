### 1.4 剩余股票的时间分布

经过 ST/BJ 前置剔除后，进入缩放处理的 4,945 只股票的日期分布如下：

#### 总体情况

-   日期范围: **2016-01-04 ~ 2026-05-29**（共 2,525 个交易日）
-   总数据行数: ~9,474,585
-   所有股票的结束年份均为 **2026 年**（全都在 2026-05-29 仍有数据）

#### 股票起始年份分布

| 起始年 | 股票数 | 占比 | 说明 |
| --- | --- | --- | --- |
| 2016 | 2,597 | 52.5% | 从数据起始日就在交易的老股票 |
| 2017 | 415 | 8.4% |  |
| 2018 | 102 | 2.1% |  |
| 2019 | 198 | 4.0% |  |
| 2020 | 390 | 7.9% |  |
| 2021 | 477 | 9.6% |  |
| 2022 | 336 | 6.8% |  |
| 2023 | 235 | 4.8% |  |
| 2024 | 77 | 1.6% |  |
| 2025 | 90 | 1.8% |  |
| 2026 | 28 | 0.6% | 当年新上市 |

#### 完整覆盖分析

-   **2,187 只股票**（44.2%）完整覆盖了整个数据期（2016-01 ~ 2026-05），拥有超过 10 年的连续交易数据
-   **4,913 只股票**（99.4%）在 2026 年 1 月至 5 月期间有交易数据
-   28 只 2026 年新上市的股票仅有不到半年的数据

#### 数据长度分布

| 数据长度（行数） | 股票数 | 特征 |
| --- | --- | --- |
| < 120 行 | 43 | 2026 年刚上市的次新股 |
| 120 ~ 500 行 | 126 | 2025~2026 年上市的次新股 |
| 500 ~ 1,000 行 | 512 | 2022~2024 年上市的相对新股 |
| 1,000 ~ 1,500 行 | 908 | 2020~2022 年上市 |
| 1,500 ~ 2,000 行 | 324 | 2018~2020 年上市 |
| 2,000 ~ 2,500 行 | 1,611 | 2017~2018 年上市 |
| 2,500+ 行 | 1,421 | 2016 年起就在交易的"老股票" |

#### 数据规模汇总

| 指标 | 数值 |
| --- | --- |
| 原始 A 股全市场股票池 | 5,517 只 |
| 剔除 ST/\*ST/退市股（263只）+ BJ股（313只）后 | 4,945 只 |
| 进一步剔除停牌股（19只）+ 短历史新股（44只）后 | ~4,900 只 |
| 总数据行数 | ~9,470,000 |
| 日期范围 | 2016-01-04 ~ 2026-05-29 |

**关键结论**：剩余股票池以 2016 年起持续交易的长期股票为主体（52.5%），叠加逐年上市的新股，构成时间跨度超过 10 年、覆盖全市场的训练集。

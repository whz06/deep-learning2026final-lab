## 回测过程说明

### 逐日流程

```
每个交易日 D（signal_date）：
  1. 加载 CNN-LSTM 模型对 D 日收盘的预测结果
  2. 计算 pred_ret = pred_raw / cur_close - 1（预测收益率）
  3. 按 pred_ret 降序排列，取 Top N 作为目标持仓
  4. 计算当日持仓收益：
     - 持仓选自前一日（D-1）的 Top N
     - 当日收益 = 持仓股在 D 日实际收益率（real_ret）的等权均值
  5. 换手：卖出现持仓中 pred_ret 最低的 K 只 → 买入目标中最高且未持有的 K 只
  6. 若 CSI5d < -1%：目标持仓从 N=5 降为 N=4（减仓 20%）
```

### 收益对齐说明

| 日期 | 操作 | 实际收益 |
|:----:|------|:--------:|
| D+1 = 2026-01-05 | 买入 Top 5（空仓建仓） | 当日无收益（刚买入） |
| D+2 = 2026-01-06 | 换手 + 持有 D+1 所选股票 | = D+1 所选 5 只股票在 1月6日的 real_ret 均值 |
| D+3 = 2026-01-07 | 换手 + 持有 D+2 所选股票 | = D+2 所选股票在 1月7日的 real_ret 均值 |
| ... | ... | ... |

> 收益产生遵循 T+1 规则：**D 日决策 → D 日收盘执行 → D+1 日产生收益**。
> 与 `strategy.py` 原版回测的 `daily_ret = next_value / total_value - 1` 逻辑一致。

## 结果分析

### 1. 负收益原因

CNN-LSTM 模型在测试期（2026-01 ~ 2026-05）未能产生正收益，主要可能原因：

| 原因 | 说明 |
|------|------|
| **模型设计差异** | CNN-LSTM 是价格回归模型（MSE loss 拟合 close 价格），不是排序模型。IC=0.118 是价格预测精度，不是排序质量。价格预测准确 ≠ 排序准确 |
| **信号密度低** | 每日仅约 102 只股票有信号，选股池只有 v7 模型的 1/5，头部股票区分度不足 |
| **单特征局限** | 仅用 maxmin 归一化的 close 价格作为输入，缺少技术指标、截面排名等信息，难以捕捉跨股票相对强弱 |
| **市场环境变化** | 测试期（2026 年初）市场波动较大，单一价格趋势模型可能不适应 |

### 2. 回撤与波动

- 最大回撤 **-27.62%**，集中在 2026 年 1~2 月的市场回调期
- 年化波动 **31.50%**，与 N=5 集中持仓的高波动特性一致
- 风控触发率 23.2%，与 v7 回测的 37.8% 相比偏低（可能因信号期不同导致 CSI5d 值有差异）

### 3. 交易成本

总成本 **6.11%**，在 -4.01% 的累积收益中占比显著。N=5 持仓集中 + K=3 换手较快，成本对净收益的影响较大。

## 结论

1. CNN-LSTM 模型在 N=5, K=3 统一评测框架下录得 **-4.01%** 的累积收益（Sharpe -0.19），未能跑赢基准
2. 相比 v7 排序模型（+18.71%），负收益的主要原因是**模型类型差异**——回归模型的价格预测能力不能直接转化为排序能力
3. N=5 集中持仓放大了模型预测偏差的影响，每日仅 102 只股票的选股池也限制了模型发挥
4. 交易成本（6.11%）在负收益环境下进一步拖累了净回报
